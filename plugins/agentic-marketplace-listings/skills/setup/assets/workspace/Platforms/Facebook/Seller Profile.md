# Facebook Marketplace Seller Profile
This seller-owned file controls how your Facebook Marketplace listings sound and which recurring practices the agent should use. Edit it freely; system updates must not overwrite it.
## Voice and tone
Describe how you want listings to sound, such as friendly, direct, conversational, concise, or detailed.
## Standard practices
Record recurring preferences such as pickup area, delivery availability, payment expectations, or whether standard language should be included only when relevant.
## Writing preferences
Record formatting, phrases, details, or habits you want used or avoided.
## Approved examples
Paste a small number of finished Facebook Marketplace listings whose voice you want the agent to emulate. Label each example clearly. Examples teach style only; their facts, prices, and condition do not apply to new items.
