# eBay Seller Profile
This seller-owned file controls how your eBay listings sound and which recurring practices the agent should use. Edit it freely; system updates must not overwrite it.
## Voice and tone
Describe how you want listings to sound, such as precise, collector-oriented, neutral, concise, or warm.
## Standard practices
Record recurring preferences such as shipping language, handling expectations, returns wording, or other seller practices. Do not treat this file as a substitute for current eBay policy.
## Writing preferences
Record formatting, phrases, details, or habits you want used or avoided.
## Approved examples
Paste a small number of finished eBay listings whose voice you want the agent to emulate. Label each example clearly. Examples teach style only; their facts, prices, condition, and item specifics do not apply to new items.
